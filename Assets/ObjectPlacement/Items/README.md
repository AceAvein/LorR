# Object Placement Items (CC0)

Sources:
- Kenney Food Kit — https://kenney.nl/assets/food-kit (Fruits, Vegetables, Beverages, Fragile)
- Quaternius Ultimate Food Pack — extra fruit meshes
- Kenney Furniture Kit — https://kenney.nl/assets/furniture-kit (Gadgets)

## Folders
| Folder | Box | Category |
|--------|-----|----------|
| 01_Fruits_Yellow | Yellow | Any fruit |
| 02_Vegetables_Red | Red | Any vegetable |
| 03_Beverages_Blue | Blue | Sealed / to-go drinks only (no glassware) |
| 04_Fragile_Green | Green | Breakable non-drink (plates, bowls, pots) |
| 05_Gadgets_Brown | Brown | Electronics / small appliances |

## Textures
Kenney Food FBX expect `Textures/colormap.png` next to the models (already set).

Furniture gadgets are often vertex-colored in Kenney's pack; scale large items (TV, microwave) down to hand size for the conveyor.
